# deepcut-videos

Moteur vidéo du compte TikTok Deep Cut (@deepcut.kpop).

- `engine.py` : transforme un fichier de sujet (JSON) en vidéo verticale avec bande-son.
- `RUNBOOK.md` : procédure suivie par chaque passage automatique.
- `stories/` : fichiers de sujets, dont deux exemples.
- `posted.md` : journal des publications.
- branche `videos` : vidéos du dernier passage, écrasée à chaque fois.
